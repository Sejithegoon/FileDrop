Changelog

Every WiFiDrop release, newest first.

0.1.2 beta · October 18, 2026

  • The data folder moves from %ProgramData%\FileDrop to %ProgramData%\WiFiDrop automatically the first time WiFiDrop starts. Nothing is lost; if it can't be moved, WiFiDrop keeps using the old folder.
  • Tidier internals: the last FileDrop names inside the app are now WiFiDrop.

0.1.1 beta · October 18, 2026

  • FileDrop is now WiFiDrop, with a new home at wifidrop.ca.
  • Updating keeps your files, accounts, settings and Pro licence. The installer removes the old FileDrop startup entry and firewall rule.

0.1.0 beta · October 16, 2026

First public beta.

  • Desktop admin window with tray icon; closing the window keeps WiFiDrop running.
  • Choose the storage folder at first run and move it later.
  • User accounts with temporary passwords, suspend, reset and delete.
  • Private folders, subfolders, move, rename and Trash with restore.
  • Shared folders with View, Upload and Manage access.
  • Resumable chunked uploads, several files at once, any file type.
  • Storage limits per person and per shared folder.
  • Pause uploads or downloads; see signed-in devices and running uploads.
  • HTTPS on the local network with a one-time phone warning, plus a help page for plain http:// links.
  • Optional admin window PIN; data folders restricted to the Windows account running WiFiDrop.
  • Database backup before every upgrade; items in the Trash for over 30 days are removed automatically.
  • WiFiDrop Free includes up to 5 accounts. WiFiDrop Pro (in testing) adds unlimited accounts and scheduled backups of files and accounts to another drive.
  • Licence screen: paste a Pro licence, see its status, or move it to another PC. Pro works offline.
  • "Update available" notice in the admin window when a new version is out, and a Send feedback button that opens the feedback form.
  • About page listing every open-source component and its licence; the installer shows the licence agreement.
