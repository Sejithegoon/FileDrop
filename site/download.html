Requirements

  • Host PC: Windows 10 (version 1809 or later) or Windows 11, 64-bit.
  • Microsoft Edge WebView2: built into Windows 11. On Windows 10 it's usually already installed. If the admin window stays blank, install the WebView2 Runtime.
  • Disk: about 200 MB for the app, plus space for the files people upload.
  • Phones and computers that connect: any recent browser (Safari, Chrome, Edge or Firefox) on the same Wi-Fi or hotspot.

Install

  1. Run FileDrop-Setup-0.1.0.exe.
  2. The beta isn't code-signed yet, so Windows may show "Windows protected your PC". Click More info, then Run anyway. If you want to be sure first, check the SHA-256 (below).
  3. Choose whether FileDrop starts when you sign in. The installer also adds a Windows Firewall rule so phones can connect.
  4. FileDrop opens and asks where to save uploaded files. Then follow the setup guide.

Check the download

In PowerShell, in your Downloads folder, run:

Get-FileHash .\FileDrop-Setup-0.1.0.exe

The result should match the SHA-256 above exactly.

Uninstall

Go to Settings → Apps → FileDrop → Uninstall. Uninstalling never deletes the files people uploaded or your accounts. They stay in your storage folder and in %ProgramData%\FileDrop, so reinstalling picks up where you left off.
